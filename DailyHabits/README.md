# Daily Habit Tracker 🚀

A responsive Daily Habit Tracker application built using React.js. This application helps users manage their daily habits, track completion, monitor progress, and visualize their activities through charts.

## ✨ Features

- **Habit Management:** Manage daily habits through an organized interface.
- **Daily Completion:** Track daily habit completion.
- **Dashboard:** View habit-related information through dashboard cards.
- **Progress Visualization:** Display progress using bar charts and pie charts.
- **Reusable Components:** Organized UI components for better maintainability.
- **Responsive UI:** Clean and user-friendly interface.

## 🛠️ Technologies Used

- **Frontend:** React.js, JavaScript (ES6+), JSX
- **Styling:** CSS3
- **UI Components:** Reusable React Components
- **Charts:** Recharts
- **State Management:** React Hooks
- **Storage:** Browser localStorage

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/NalinaDevdasMeshram/XHabitTracker.git
```

### 2. Navigate to the project directory

```bash
cd XHabitTracker/DailyHabits
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in browser

```text
http://localhost:5173/
```
